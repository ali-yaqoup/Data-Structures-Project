### 🔹 Task 3  
Implementation of a **Postfix Expression Evaluator** using the C++ `stack` STL.  
Evaluates multi-digit postfix expressions using stack-based parsing.

---

### 🔹 HW#222  
An object-oriented project using class inheritance for geometric shapes.  
Includes:
- `Shape` (abstract base class)
- `Circle`, `Rectangle`, etc.
- Virtual functions for area calculation and coordinate handling.

---

### 🔹 HW#111  
A C++ class for **Polynomials** supporting:
- Dynamic array resizing
- Operator overloading: `+`, `-`, `+=`, `-=`, `=`
- Input/output using `cin` and `cout` via overloaded `>>` and `<<`

---

### 🔹 Assignment 4  
A templated **Double-Ended Queue (Deque)** implementation using a doubly linked list.  
Features:
- `pushFront`, `pushBack`, `popFront`, `popBack`
- Access to front/back values
- Dynamic size handling

---

### 🔹 DS Project  
A templated **Linked List** with:
- `addFront`, `addBack`, `removeFront`, `find`, and `traverse`
- Custom function `removeBefore(x)` to delete the node before a target element
