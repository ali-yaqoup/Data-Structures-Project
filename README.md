# 📘 Data Structures Homeworks – Ali Derar Ali Yaqoub

This repository contains selected homework and practical tasks from the Data Structures course.

## 🧩 Included Projects

### 🔹 Task 3
Implementation of a **Postfix Expression Evaluator** using the C++ `stack` STL.  
The program reads a postfix mathematical expression with multi-digit numbers and evaluates the result by pushing and popping operands and operators from a stack.

### 🔹 HW#222
A **Shape Hierarchy** project using C++ object-oriented programming with inheritance and polymorphism.  
Includes:
- `Shape` (abstract base class)
- `Circle` and other derived shapes that override virtual functions to compute areas and display coordinates.
